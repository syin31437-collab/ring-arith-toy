标量、无噪声、中央观察者、加性同灵敏度这四条里，T0 的不可区分、T1 的共同偏移不变性、T3 的 m ≥ e+1 / m ≥ 2e+1，推导站得住。会把结论说错的，是把这四条写成了更宽的定理，以及 B、E 把另一套模型的通过当成了这套定理的确认。

最可能错的三件事：

1. **T5 的“当且仅当”和 T6 的隐身预算上限**，在故障落进观测映射的零空间时不成立，伤害可以任意大而残差不变。
2. **v6.1 的“诚实后验”**不是 T6 那个均值偏移模型的后验；τ 用了注入幅度 δ，方差又按题数而不是块数。0.071 是这套插件的拟合，不是定理的推论。
3. **z 公式的预注册检验第一轮没过**（Spearman 0.78 / 0.71）。第二轮改了公式、改了 δ、拿实测基础率 b 补上，才过线。

下面每条都是能落地的攻击。经得起打的，在各节末尾标明。

## A. 阶梯

### A1. T5：可见性写成了残差的性质

- **类型**：数学错误
- **严重度**：严重（这句话要收窄；收窄后的特例仍在）
- **证据**：`ladder.md` T5 证明写的是 `Ay = c + Af + Aε`，Af = 0 时推出“分布不变”，再写成“f 可见 ⇔ Af ≠ 0”。变的只是 **A y 的分布**。全观测 y 可以照样变。

反例。θ = (θ₁, θ₂)，约束 θ₁ − θ₂ = 0。两个来源，f₁ = (0,0)，f₂ = (1,1)。A f₂ = 0，两份报告仍差 (1,1)。比一下两个来源，检出概率随样本量趋于 1。约束残差始终不含这个 f。

同一句话里的密度例子（错人口、错面积、错密度互相一致）是非线性流形上的有限位移，线性式 Af = 0 覆盖不到。那个例子要另证：单个派生链上，流形内的位移能被吸进另一个合法 θ，这是 T1 的重参数化，不是 T5 这行代数。

- **判决检验**：用上面这个两来源反例跑 `ladder2` 的同伴比较。Af = 0 且同伴差的统计量越过阈值，T5 的“⇔”就被否定。若改成单来源、只看 A y，则检不出，收窄后的句子成立。

### A2. T6 隐身预算不是上限

- **类型**：数学错误（和 T5 直接矛盾）
- **严重度**：严重
- **证据**：T6 写“累计造成的偏差上限约 σ√(2T log γ)”。常数偏移、单一高斯通道、已知 μ 的 LLR 阈值 log γ 下，代数是对的：每题 KL = μ²/(2σ²)，T · KL = log γ 推出 |μ| = σ √(2 log γ / T)，累计 T|μ| = σ √(2T log γ)。

这个数只描述 **这一条可观测通道上的常数偏移**。T5 的核里 Af = 0，残差 LLR 每步都是 0，累计伤害可以任意大，检测率和没注入时相同。Liu–Ning–Reiter 的虚假数据注入就是这个构造在电网残差上的现成形式；Chow–Willsky 1984 的 parity 不可观测子空间是同一条定理。T6 的“上限”没有排除这个核。

慢漂移那一行也不是 Lorden 定理。Lorden 1971 / Moustakides 1986 是 **突变后分布已知且固定**。μ_t = v·t 的累计 KL = Σ (vt)²/(2σ²) = v²T³/(6σ²) 只是独立高斯能量相加，检测延迟把它设成 log γ 是启发式。立方根量级在渐变变点文献里常见，常数 6 不是最优检验的定理。

- **判决检验**：固定同一个 |z|>3 检测器，一种攻击沿可观测方向放常数 μ，另一种把同幅度的偏移放进 A f = 0 的方向。前者累计到大约 σ√(2T log γ) 时应开始报警；后者报警率应停在零注入水平，而累计偏差随 T 线性涨。第二条一出现，这句话就不是上限。

### A3. 阶梯把“看见有人不同”写成了“知道自己偏了”

- **类型**：假通过
- **严重度**：严重（研究问题的那一格是错的；T3 的形式定理还在）
- **证据**：标题问的是系统能否知道 **自己** 偏离。预言表写“多数节点偏 / 只看同伴 / 能检测，认错人”。T3 的假设是偏好最少故障。m ≤ 2e 时，错的多数是最大一致类，最少故障解释会把少数干净节点判成故障，系统输出多数的值，并且认为输出是干净的。

这时同伴比较看得到分裂，所以“存在不一致”为真；“知道自己的输出偏了”为假。这一格回答的是前一件事。全员同偏那一格写“不能”，反而和问题对齐。

- **判决检验**：e 个一组同偏、干净节点少于 e，融合规则取最大一致类。记录两件事：不一致报警是否响起，以及输出相对真值是否偏离。前者应为响，后者应偏离且系统把偏离记在少数头上。第二项成立，则这一格不能算研究问题上的成功。

### A4. “一把历史先验测不到慢漂移”和 T2 自己的公式冲突

- **类型**：数学错误（内部不一致）
- **严重度**：严重
- **证据**：T2 设 θ_t 独立同分布、方差已知。共识均值偏移 μ 的 KL = μ² / [2(σ_θ² + σ²/k)]，这是高斯位置族的标准 KL。慢漂移 μ_t = v·t 的能量同样会积到 log γ，延迟量级就是 T6 那个立方根，只是分母里的方差换成 σ_θ² + σ²/k。阶梯表却把“自身历史 + 真值先验”一行的“不可能”写成“变慢的漂移”。

在 T2 的假设下，慢漂移改变 ȳ 的边缘分布，检测得到。分不开的是另一件事，同一行已经写了：真值变了还是大家一起偏了。预言表“只看同伴 / 全员慢漂移 / 不能”指横截面同伴、不使用这条先验，那一格没问题。

- **判决检验**：θ_t 用 N(0, σ_θ²) 仿真，全体 f 从 0 线性增到 2δ，只用共识对 0 的 CUSUM，误报间隔约束在 γ。延迟应随 (σ_θ² / v²)^{1/3} 走，而不是永远不报警。

### A5. T3 的阈值是 p = 1 的特例；RAIM 那句对不上这个式子

- **类型**：隐含假设（外推时变成数学错误）
- **严重度**：中等（标量模型内部的证明是对的）
- **证据**：模型段 y = θ_t + f + ε，θ_t 是标量。无噪声时：不可见当且仅当偏移向量为常数；至多 e 组里出现全员同偏，必须 e ≥ m，所以检测要 m ≥ e+1。定位的补集论证也成立：m ≤ 2e 时可以把 F 与补集都控制在 e 以内，T1 把“F 偏 +g”变成“补集偏 −g”；m ≥ 2e+1 时干净组至少 e+1，任何非零偏移类至多 e 个，最大一致类唯一。这就是重复码的检测/纠正，也是 Hamming 界在距离 m 的重复码上的样子。

RAIM 的 5 星检测、6 星排除不是这个式子算出来的。定位要 4 个未知数，冗余度 m − p，检测要冗余 ≥ e，排除要冗余 ≥ 2e，所以 5 = 4+1，6 = 4+2。用草稿里的式子会得到检测 2、定位 3。表里“有一个可信来源就能定位任意多个”是对的，它说明阈值随信任假设变；它也说明阈值随 **H 的列空间** 变。一般形式是：f 不可见当且仅当 f 落在观测矩阵的列空间里。T1（列空间 = 常数向量）、T3（p = 1 的组合推论）、T5（parity 矩阵的核）是同一句话的三个特例。

“n 节点互看最多认出 (n−1)/2”把中央观察者的界套进了互看。草稿自己在下一行引 Lamport–Shostak–Pease：没有中央观察者、能对不同对象说不同的话，是 n ≥ 3e+1。Dolev–Strong 1983 在有签名时放到 n ≥ e+1，草稿“可大幅放宽”这句方向是对的。

- **判决检验**：把 θ 改成 R⁴ 的位置加钟差，H 用真实星座几何，e = 1。不可见故障应出现在 m = 4 而不是 m = 2；能排除单星应出现在 m = 6 而不是 m = 3。

T3 在它写明的那组假设（标量、中央观察者、对等、加性、噪声相对偏移足够小、最少故障、已知上界 e）下，必要性和充分性都成立。

### A6. 相关 0.69 不会让整数 m 减一

- **类型**：隐含假设
- **严重度**：严重（T4 的极端情形成立，文中的定量推论不成立）
- **证据**：T4 说 j 的报告依赖 i，则两条通道并成一条，并引“相关从 0.04 升到 0.69”。T3 的 m 是对抗性故障的支撑：这一组能否被 **任意** 偏移同时带动。相关系数是噪声的二阶矩。

反例：j = 0.9 ·（i 的报告）+ 0.1 ·（j 自己的私有测量）。相关可以很高，但对手若不控制那 0.1 的私有项，就不能任意指定 j。反过来，相关样本为 0 也不妨碍存在一个这次没发作的共享故障通道。

互动也不单调减少可区分性。若互动带来的是外部测量而不是互相抄答案，那是 T0 的第一种杠杆，m 上升。

“互动前留存独立答案”只在互动会覆盖私有测量时成立。

- **判决检验**：固定边缘相关 0.69，比较两种数据：线性拷贝，和对私有测量加相关噪声。只对前者做 T3 的补集构造（i 任意偏、j 被迫跟着偏）。后者应仍能分开 i 和 j 的偏移。

### A7. 按需去查秤，正好让阈值下的对手永远不被查

- **类型**：反例
- **严重度**：严重
- **证据**：agent 段写“平时不用常设的秤，可疑时才查”。可疑性若由便宜检测器决定，对手把可观测方向的偏移放在 A2 的检测线以下，触发器不响，独立来源永远不被调用。系统停留在 T1/T2。T0 意义上的新观测没有发生。

自适应地决定查不问，还会把单次检验的 γ 变成可选停止后的 γ，原阈值不再是误报界。

重新校准会把慢漂移吸进基线，这句话和 T2、T6 一致，成立。

- **判决检验**：便宜检测器阈值固定，对手每步偏移取该阈值对应的 μ 的一半。独立来源的调用次数应为 0，输出的累计偏差应随 T 线性增加。把秤改成每步都在，同一攻击应在 T6 的时间尺度上报警。

### A8. T0、T1、T2 里站得住和只是写松的部分

T0“存在一对 w ∈ D、w' ∈ N 使 P_w = P_w'，则任何算法在这一对上不能好于随机”是定义的直接推论，成立。Le Cam 那一行在 TV 取 [0,1]、总错误指两类错误之和时，是复合检验的标准下界，成立。

“误报固定、漏报按 exp(−T·KL) 下降”是 Stein 引理的体制，不是 Chernoff。Chernoff 信息是两类错误同时指数下降时的速率，一般严格小于那个 KL。KL 的方向也没写。这是表述错误，不推翻后面的公式。严重度：轻微。

T1 的路径恒等 y = (θ+g) + (f−g) + ε 在模型内部成立，而且是逐点成立，不只是分布成立。成立条件是：每个来源对 θ 的灵敏度相同，噪声定律不依赖 (θ, f) 的分解。灵敏度 α_s 不同时，公共加性故障和 θ 的移动不再是同一个观测：反例 y_s = α_s θ + f_s + ε，α 不全相等。严重度：中等，因为表里那一行没再写 α_s = 1，模型方程里写了。

T2 的 KL 和 Lorden 首项在“高斯、独立、变点前后分布已知、突变”下成立。1.2533 和中位数无关时，共识若是中位数而不是均值，高斯下方差多 π/2，延迟预言偏快这么多。非高斯、方差有限的位置族，Fisher 信息不低于 1/v，高斯是局部最慢的检测，不是普遍常数。严重度：中等。θ 的分布自己变了就退回 T1，这句成立。

## B. v6.1 的后验，和 T6 不是同一个模型

### B1. “真正的后验”是随机效应边际，不是均值偏移

- **类型**：隐含假设（相对 T6 是数学错误）
- **严重度**：严重
- **证据**：`law_v6.py` 的 `fit`：

```python
v = (1.2533 * _mad(X)) ** 2 / len(bad) + se_b ** 2
tau = st.median(x for *_, x in bad)
lr = sqrt((v+τ²)/v) * exp(−½ x̄² (1/v − 1/(v+τ²)))
ph = lr / (1 + lr)
```

这是先验 ½、诚实 x̄ ~ N(0, v)、故障 x̄ ~ N(0, v+τ²) 的边际似然比，代数和 `ph = lr/(1+lr)` 没错。N(0, v+τ²) 是“偏置本身 ~ N(0, τ²)”积分掉之后的分布。

T6 写的是固定均值偏移、KL = μ² / [2(σ_i²+σ_c²)]。那条备择下的似然比是点备择 N(μ, v) 对 N(0, v)，指数项线性于 x̄，不是 x̄² 的方差膨胀。文档第 4 条结论又写故障主要是“偏”不是“变吵”。`fit` 的备择正是变吵（方差从 v 到 v+τ²，均值仍是 0）。

大 |x̄| 两种模型都会把 ph 拉向 0，所以注入实验里排序还可以。概率值没有理由等于“该节点被毒了”的后验，除非毒的幅度真是从 N(0, τ²) 抽的、先验概率真是 ½、而且 v 是对的。

τ 取评估段第四列的中位数。第四列在 `item_probs` 里同时定义 t = δ_k / 2，也就是“被骗”这个事件的宽度。事件宽度用 δ 是评分定义，公平。再把同一个 δ 当作故障先验的标准差，是多出来的：预测器读到了攻击幅度。自然故障没有这个幅度。证据链自己写自然格高估约一倍，和“τ 按注入 δ 设定、自然故障对不上”一致。

- **判决检验**：同一批注入数据，把故障似然换成 N(δ, v)（符号已知）或 ½N(δ,v)+½N(−δ,v)，先验改成真实投毒比例，重算被骗率。若 MAE 相对现在的 N(0, v+τ²)、先验 ½ 明显变好，现在的“后验”就不是数据在 T6 模型下的后验。自然故障格子再用注入 δ 做 τ，高估应还在；用残差自身估 τ 之后高估应下降。

### B2. 诚实方差除的是题数，块结构只进了区间

- **类型**：代码缺陷
- **严重度**：严重
- **证据**：`fit` 里 `v` 除以 `len(bad)`。`interval` 另写 `ne = len(set(blocks[1]))`，注释说明联邦学习按块重采样后，覆盖从 44% 到 94%，宽度从 0.14 到 0.41。诚实后验没用这个 ne。同一轮里的题若是重复样本，v 偏小的因子大约是题数/块数，|x̄|/√v 偏大，ph 被推离 ½。点预测因此比区间更自信。文件头把 v6.1 的地板修正归因于 Fashion-MNIST 沙盒里“估 0.05、实际 0.38”：修正形式参照了真实秤方差。测试 MAE 是否独立，取决于沙盒和 `validate_v61.py` 的格子是否分开，这要看 git，材料里看不出。

1.2533 × `_mad`（`_mad` 已含 1.4826）是高斯中位数标准误，不是重复乘了两次。留一法除以 √(1 + π/(2(n−1))) 同样只在高斯、节点独立时把“节点减他人中位数”还原成 σ。这两处代数在高斯下是对的。

- **判决检验**：`v` 的分母改成评估段块数，其余不动，重跑 `validate_v61.py`。联邦学习格子的 ph 应向 ½ 靠，MAE 的变化若超过报告的 0.071 的不确定度，现在的校准就依赖这个偏小的 v。

### B3. 0.071 度量的是“评估段上的插件”，μ 的理论没有被这个数证实

- **类型**：隐含假设
- **严重度**：中等
- **证据**：`ph`、`b`、`vc`、`λ_c` 都在 `bad` 上估计，再在同一批 `bad` 上算 q。q 没用真值，所以不是标签泄漏。它也不是校准期对未来的预测。`subsets` 用独立伯努利(ph_i) 抽 64 次；ph_i 是对秤的边际，不是子集的联合后验。种子固定为 0，蒙特卡洛误差不是 0.071 的主要来源。

T6 说 ρ、κ“就是”检测信噪比。v6.1 的输出是子集混合高斯尾概率，不是证据链里那个 sigmoid(wᵀ quad(log ρ, log κ, log λ, q))。现行结论写的算法是 v6.1，规律本体仍印着 sigmoid。T6 解释的对象和被验证的对象不是同一个。理论草稿日期是 2026-11-02，`LAW_VERSION = "6.1"` 的注释是 2026-11-01：这页阶梯是事后解释。这不等于实验违反预注册；预注册要看 tag 相对运行的 git 顺序，材料里没有 log。

- **判决检验**：把 `validate_v61.py` 的预测换成只含 log ρ、log κ 的 sigmoid（玩具上的旧权重），看 MAE 是否仍为 0.071。两者若分开，则 0.071 不能当作 T6 或 sigmoid 规律的证据。

`item_probs` 里把裁判输出 o 当作给定、θ 取后验，再算 P(|o−θ| > t)，这一步在“后验正确”的前提下是对的：o 是数据的函数。错在后验，不在这行 Φ。

## E. z = μ / se

### E1. 预注册的公式没过；过线的是后改的公式

- **类型**：假通过（预注册）
- **严重度**：致命（对“零拟合的 z 预测了检出率”）；不推翻“加了实测基础率之后，在后选的 δ 上单调关系还在”
- **证据**：`distinguish.py` 文件头。第一轮预注册 Spearman ≥ 0.80、MAE ≤ 0.15。结果 Spearman 0.78 和 0.71，MAE 0.066 和 0.135。原公式的排序没过。

第二轮同时改了三件事：δ 改到过渡区（因为第一轮几乎全是 1.00）、预测改成 1−(1−P)(1−b)、b 用窗口奇偶交叉估计，并丢掉 L0 上 z = 0 的格子。门槛改成 Spearman ≥ 0.80、MAE ≤ 0.10、过渡区至少一半。结果 0.92 / 0.082 / 65% 和 0.86 / 0.038 / 52%。

零假设已经对不上：S0 实际 0.31（SLQA）和 0.59–0.65（BIPM），正态 |N(0,1)| > 3 再按独立乘起来，预测只有 0.02–0.03。差一个数量级。t 分布或 MAD 的估计误差给不出 50% 的超线率。文件把原因写成自然故障，并承认也可能是厚尾或时间相关让标准误偏小，而且写了“未验证”。第二轮把这个未解释的量做成了 b。过线的是“z 加上实测基础率”，不是 z。

z = 0 的格子被说成“构造决定”。μ 来自 `shift_of`，和注入是同一个向量，不可区分是代出来的，不是测出来的。第二轮还把这些格子排除了。T1 的不可能没有被这个实验独立支持；T1 自己的代数已经够了。

窗口的 AUC 在写公式之前看过，文件自己写了。δ 网格和 b 的加入发生在第一轮失败之后。这是确认偏差，不是又一次独立确认。git 能否证明 0.80/0.10/50% 出现在 `79374ca` 之前，材料里看不到。

- **判决检验**：冻结第一轮的 `p_over(μ/se)`，不许乘 b，在第二轮的 δ 上重算 Spearman。不过 0.80，则第二轮的通过来自 b 和选网格。另做：校准期内打乱时间、保持边际尺度，重算 S0 超线率。仍接近 0.31 和 0.6，标准误公式就是错的；掉到约 0.003，自然故障的解释才成立。

`p_over` 本身：1 − (Φ(3−z) − Φ(−3−z)) = P(|N(z,1)| > 3)，写对了。

### E2. 多条序列按独立相乘，在共享噪声下可以任意偏

- **类型**：数学错误（文中标了“近似”，所以不构成隐瞒）
- **严重度**：中等
- **证据**：`cell` 里一级检测 P = 1 − Π(1−P_i)。`series` 的 nodeA 都减去同一个 A，consA 是中位数减 A，AB 是 A−B。尺度场景下每个 nodeA 的 μ 都是 −δ（`shift_of`），统计量共享 A 的误差。

反例：n 条完全相同的序列，每条边际超线概率 p。公式给出 1−(1−p)^n，真实并集概率是 p。p = 0.3、n = 10 时，0.97 对 0.3。边际 z 全对，合并概率可以错到 MAE 门槛外面。

相关大约是 σ_A² / (σ_节点² + σ_A²)。秤很准时这个近似碰巧还能用，所以 BIPM MAE 0.038 并不奇怪，也并不证明乘积公式对。L2 与 L3 共用序列、组间不独立，0.80 不是按独立组数校准过的门槛。文件已经写了组间不独立。

漂移的 se 另有一处：`extra = |μ| · 1.4826 / 2` 加进噪声方差。线性漂移是确定性信号。评估段中位数的抽样方差仍由噪声决定，不把斜坡的散布当成白噪声。斜坡从 0 到 2δ、μ 取 δ，和 `2 * s[j] * (t+1) / T_` 的时间平均大致一致，信号位置这步没大错；错在 se 被放大、漂移格的 z 被压低。

- **判决检验**：尺度场景里抽出各 nodeA 统计量的样本相关。用这个相关做高斯耦合，算并集概率，减去现在的独立乘积。差值若经常大于 0.10，E 的 MAE 是格与格抵消出来的，不是公式校准了。

## 站得住的部分

- 一对世界观测分布相同，就无法在这对世界上做更好的检验。
- 在 y = θ + f + ε、各源灵敏度相同、噪声不依赖分解时，(θ, f) 与 (θ+g, f−g) 逐点相同。只有差 f_s − f_r 可辨识。
- 标量、中央观察者、任意加性偏移、至多 e 组、无噪声：检测要 m ≥ e+1，定位要 m ≥ 2e+1。换一个可信源，界就消失。草稿把 v1 的“通用阈值”降级，这一步是对的。
- 最后那句“不能说 k 个来源就能检测 e 个故障，除非写明观察者、信任和故障模型”，是这叠草稿里不该收回的句子。
- 高斯独立、突变、分布已知时，延迟首项 log γ / KL，KL = μ²/(2v)。
- 两把秤同时被污染则两把一起瞎。`premise2.py` 把漏报写成这个，和 T1 一致。

材料没包含 `ladder2.stat`、`validate_v61.py` 和 git log。E1 的“stat 用的是不是同一套中位数标准误”、B2 的沙盒是否等于测试格、预注册数字是否写在运行之前，这三件要看那些文件才能定死；上面的判决检验就是为它们写的。
