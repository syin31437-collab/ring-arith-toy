# 一个系统要知道自己偏离了，最少需要什么（草稿 v2，2026-11-02）

**v2 的改动（外部审稿意见）**：v1 把 m ≥ e + 1、m ≥ 2e + 1 写得像通用阈值，这是错的，它们只在一组特定假设下成立。v2 把**观测可区分性**放到最底层（T0），其他全部降级为它在具体假设下的推论。
大部分零件是已知结果（下面标出来源）。这份草稿没有经过专业审阅。

## T0 观测可区分性（底层）

**世界** w = 真值 + 各来源的故障情况。W 是系统认为可能的世界集合（系统的假设就体现在这里）。观测规则决定每个世界产生的观测序列分布 P_w。
正常世界集 N，偏离世界集 D。

- **不可能性**：若存在 w ∈ D、w' ∈ N 使 P_w = P_w'，任何算法、任何数据量都不能在这一对世界上比瞎猜好。（定义直接得到。）
- **一般下界**（Le Cam）：任何检验的最坏总错误 ≥ 1 − TV(conv{P_w : w ∈ N}, conv{P_w : w ∈ D})。两团分布的凸包重合得越多，越检测不了。
- **定位**：同一判据用在"故障类 F₁ vs F₂"上。
- **速率**（独立同分布、简单假设时）：误报固定，漏报按 exp(−T·KL) 下降（Chernoff–Stein）；变点检测的延迟 ≈ log γ / KL（Lorden 1971）。可区分性是一个量，不是开关。序列相依、节点会适应时，要看整条序列的分布，这个简单公式不再直接适用。

**由此，提高"知道自己偏离"的能力只有两种杠杆**：
1. **增加观测**：更多来源、任务内的约束、主动查询，让不同世界产生不同的数据。
2. **收窄世界**：加假设（某来源可信、真值分布已知、故障是稀疏的）。假设错了，结论也跟着错。

**"偏离"要说清相对什么**：
- 相对**系统自己的过去**：N = 观测分布和校准期相同。任何改变观测分布的变化都原理上可检测，但分不清是系统变了还是世界变了。
- 相对**真值**：N = 系统没错。这要靠真值和观测之间的联系，只比较系统内部永远不够（T1）。

## 下面都是 T0 在具体假设下的推论，不是通用阈值

| 假设 | 结论 | 来源 |
|---|---|---|
| 对真值一无所知，只看来源之间 | 全体相同偏移不可见（T1） | T0 |
| 中央观察者、来源对等不可信、故障只是偏移、偏好最少故障 | 检测 m ≥ e + 1，定位 m ≥ 2e + 1（T3，码距同型） | 重复码；RAIM |
| **有一个可信来源** | 能定位**任意多个**不可信节点（我们的规律：投毒过半也能认出） | **T3 的反例：换了假设，阈值就变** |
| 拜占庭、能对不同对象说不同话、没有中央观察者 | 达成一致要 n ≥ 3e + 1 | Lamport–Shostak–Pease 1982 |
| 同上，但消息有签名 | 容错可大幅放宽 | Dolev–Strong 1983 |
| 真值满足约束 Aθ = c | Af = 0 的偏移不可见（T5） | T0 |
| 故障模仿正常分布 | 对这个观测 D 和 N 重合，不可检测，哪怕有害 | T0 |

**不能说的话**：不能说"系统有 k 个来源就能检测 e 个故障"，除非同时写明观察者结构、信任假设和故障模型。

## 模型

来源 s = 1…m，题 t = 1…T：y_{s,t} = θ_t + f_{s,t} + ε_{s,t}。θ_t 是真值（未知），f 是故障造成的偏移，ε 是噪声。
**故障通道**：能被同一个原因同时带偏的来源算一组。下面的 m 数的是互相独立的组，不是节点数。

## T1 共同偏移不可见（规范不变性）

对任意序列 g_t，(θ, f) 和 (θ + g, f − g) 给出完全相同的观测分布。
证明：y = (θ + g) + (f − g) + ε，逐项相等。∎
**推论**：没有任何关于 θ 的额外知识时，只有差 f_s − f_r 可辨识。全部来源一起偏，和"真值变了"，用多少数据也分不开。

## T2 只靠自身历史：要关于真值的先验，而且慢

设 θ_t 独立同分布、方差 σ_θ² 已知，全体在某时刻起共同偏 μ。共识的逐题信息量 I ≈ μ² / [2(σ_θ² + σ²/k)]。
Lorden（1971）：任何误报平均间隔 ≥ γ 的检测，最坏延迟 ≥ (1 + o(1)) log γ / I，CUSUM 可达（Moustakides 1986）。
**预言**：延迟 ≈ 2(σ_θ² + σ²/k) log γ / μ²。真值本身变化越大，历史越没用；若 θ 的分布本身变了，退回 T1。

## T3 检测 vs 定位：一个特例（码距）

**仅在这组假设下**：中央观察者看到所有来源的同一份报告（不能对不同对象说不同话）；来源对等、都不可信；故障是加性偏移；噪声相对偏移足够小、题足够多；定位时偏好最少故障的解释。m 组来源，至多 e 组各带任意偏移。
- (a) **能检测**任意 ≤ e 组故障 ⇔ m ≥ e + 1。证明：偏移向量模常数为零才看不见，这要求全部 m 组同偏，即 e ≥ m。∎
- (b) **能定位** ⇔ m ≥ 2e + 1。证明：m ≤ 2e 时取 F 和其补集都不超过 e 组，F 偏 g 与补集偏 −g 观测相同（T1）。m ≥ 2e + 1 时，干净组 ≥ e + 1 个且偏移相同，任何故障组合成的相同类 ≤ e，最大一致类唯一。∎
工程同型：RAIM 5 星检测、6 星排除；n 节点互看最多认出 (n − 1)/2。假设一变阈值就变，见上表。

## 阶梯（只是一个例子：T3 的假设下，e = 1，节点整体当一组故障通道）

| 系统拥有 | m | 能知道 | 不可能知道 |
|---|---|---|---|
| 节点，当下（节点各自独立出错） | n | 少数节点和多数不一样 | 过半同偏时认错人；全员同偏（T1） |
| + 自身历史 + 真值先验 | — | 全员突然变了，但慢（T2） | 变慢的漂移；真值变了 vs 大家偏了 |
| + 一个独立来源 | 2 | 全员同偏（T3a） | 节点偏了还是秤偏了（T3b） |
| + 两个独立来源 | 3 | 定位哪一方（T3b） | 两方同时同向偏（等价于第三方偏） |

## T4 互动会减少 m

若 j 的报告依赖 i 的报告，i 的故障能传给 j，两者合并成一个通道。**讨论把 m 压小**：试跑里节点相关从 0.04 升到 0.69。
**推论**：讨论前的独立答案是稀缺资源；要保留检测能力，必须在互动前留存独立答案。

## T5 约束就是内生的秤（"真相被约束"）

真值满足 Aθ = c。偏移 f 可见 ⇔ Af ≠ 0。证明：A y = c + A f + A ε；Af = 0 时分布不变。∎
**推论**：留在合法区域内的错误原理上不可见。一个模型如果用一个错数推出另一个数（比如拿错的人口除面积得出密度），约束照样满足 → 看不见。约束只能查**独立得到**的量。

## T6 延迟和 ρ、κ 的关系

有独立来源时，节点 i 相对秤的逐题信息量 I = μ² / [2(σ_i² + σ_c²)]，所以延迟 ∝ 1/(μ²/σ²)：ρ、κ 就是检测的信噪比，规律里的比值在这里有了含义。
**慢漂移**（μ_t = v·t）：累计信息 v²T³/(6σ²) = log γ → 延迟 T ≈ (6σ² log γ / v²)^{1/3}。
**隐身预算**：把偏移压在检测线以下的对手，T 题内累计造成的偏差上限约 σ√(2T log γ)，不为零但只按 √T 增长。

## 对 agent（节点会学习、会主动查）的含义

- 偏离 ≠ 故障：agent 变好也是偏离。检测回答"变了"，判断好坏要靠 T3 的独立来源。
- **按需爬阶梯**：agent 能主动获取信息 = 临时增加一个独立来源。平时不用常设的秤，可疑时才查，成本低很多。但新来源必须和被查的通道独立（T4）。
- 基线会过期：agent 学习后要重新校准；重新校准会把慢漂移吸收掉（T2、T6 的盲区变大）。

## 问题与定位

一群有能力、但永远可能犯错的节点，能不能在不消灭彼此独立性的前提下，组成比任何单个节点都可靠的整体？结论是能，而且能挡住多少错误，由几个可测的比值决定；在真实 LLM 上做零重拟合盲测时，软裁判每档误差 ≤ 0.05。

- **研究对象**：已经有一定能力的节点（传感器、神经网络、LLM），它们会出错，出错方式未知。
- **不研究的**：节点完全不懂、却要凭空得出真相；或者错误出在源头、所有节点一起错（库伯的比方：拿 OnlyFans 训练，再要求写 Nature）。
- **算法的目标**：在机器一直犯错的情况下，从错误里找出错误的来源和互相影响的部分，再把错误分摊掉或消除掉。
- **核心对照**：投票（多数决）。投毒节点过半时，投票漏检 100%；用约束的裁判漏检 0–10%（盲测第二版）。

## 第一性原理

真相是被约束的，错误不是。正确答案之间互相满足某些关系（密度 = 人口 ÷ 面积，距离由坐标决定），这些关系圈出一个合法区域；错误没有理由留在区域里。

- **区域外的错误**：违反了约束，原理上可以被发现、被拉回来。
- **区域内的错误**：和约束互相一致（一组一致的错人口、错面积、错密度），原理上看不见。内部一致不等于外部真实。
- **独立性**让错误四散、跑出区域；**约束**让区域变小。分摊 = 按不可靠程度加权，把答案拉回区域。

经典理论里区域和错误的形状都是给定的；这里两者都从一直在犯的错里学出来，这可能是贡献点，但还没有查新颖性。

## 规律本体

漏检率和穿透率是一个前提加四个可测量的 S 形函数；这些量都不需要真值（σ_eff 除外），尺度一律用 MAD。δ = 故障的幅度，δ_obs = 故障题上报告中位数相对约束预测的偏移。

| 量 | 定义 | 回答的问题 |
| --- | --- | --- |
| 前提 ζ ≈ 0 | 约束和故障共享的比例 | 约束本身有没有被同一个错误污染；内部查不了，要外部锚点 |
| ρ | δ_obs / σ_eff | 能不能看出哪一拨是错的 |
| κ | δ_obs / σ_node | 能不能看出节点分成了两拨 |
| λ | δ · √k_good / σ_min | 选对了人、好节点互相平均之后，还剩多少噪声 |
| q | log δ 的分散度 | 事件大小不一时的修正；硬裁判要逐事件算 |

σ_eff = 约束预测的不确定度；σ_node = 节点噪声；σ_min = 最准节点偏离约束的幅度；k_good = 噪声不超过最准节点 2 倍的节点数。

```
P(漏检) = sigmoid( wᵀ · quad(log ρ, log κ, log λ, q) )，前提 ζ ≈ 0
```

曲线形状取决于裁判：软裁判 = 以约束预测为中心的加权中位数；硬裁判 = 剔除偏离约束 2.5 倍尺度以上的报告，全被剔除时退回中位数。w 只在玩具上拟合一次，之后一律零重拟合。违反前提以外的假设时，理论只会偏保守；只有 ζ > 0 会让它说错话。

## 证据链

从玩具到真实 LLM 盲测，每一环都是上一环暴露的问题逼出来的。零重拟合 = 曲线只在玩具上拟合，原样预测新环境；预注册 = 预测在运行前写进代码。

| 阶段 | 设置 | 关键数字 | 得出 |
| --- | --- | --- | --- |
| 1. 乘法世界 | 只靠节点间分歧消解，没有约束 | 30 个种子里 1/3 炸，全程静默 | 没有约束，一致 = 自洽的错误编码 |
| 2. ρ+κ 两比值 | 时间环境、代数环境，软 / 硬裁判 | 留出集 R² 0.85–0.95；代数→时间 0.84 | 两个比值胜过三个原始变量，单用 ρ 被证伪 |
| 3. 信息传播网络 | 30 节点小世界网络，过半阵营一起偏 | 漏检零重拟合 R² 0.72–0.83（上限 0.77–0.86） | 曲线能跨环境搬用 |
| 4. 真实 LLM PK | 7 个模型答人口 / 面积 / 密度、摩尔质量、城市距离 | 密度误差两两相关 0.98；21 个事件 19 个在区域内 | 强 LLM 的错误是共享信念，约束看不见；缺的是信息来源的独立性 |
| 5. 真实 LLM 投毒 | 5 个 DeepSeek 拿投毒资料，约束 = 模型记忆 | 原 ρ+κ 零重拟合 R² −3 | 节点噪声异质、实际传毒 ≠ δ，逼出 λ |
| 6. 异质玩具 + λ | 7 节点，1–3 个干净，部分传毒 | 投毒漏检 R² 0.39 / 0.60；回测同质环境不变差 | 第三个比值 λ 普遍成立 |
| 7. 失效地图 + 四轮预注册 | 一次破坏一条前提，每轮换新种子 | 4 轮共 16 条预测，10 条成立（0/3、2/4、4/5、4/4） | 补上好节点数、δ 分散度、MAD 尺度；只剩 ζ 会让理论说错 |
| 8. 真实盲测第一版 | 人口密度，60 国，三种约束 | 4 条对 2 条 | 失败来自世界银行真值错误 + 裁判用 SD，是假失败 |
| 9. 真实盲测第二版 | 新 60 国，投毒面积，MAD 事先写死 | 5 条对 4 条；软裁判每档误差 ≤ 0.05 | 规律在真实 LLM 上干净地盲测通过；ζ = 1 时如预言失效 |
| 10. 真实盲测第三版 | 独立 GPS 记录 + 单位换算约束，合成行程 | 4 条对 2 条；软裁判 δ=5% 差 +0.23 | 换一种约束后暴露 k_good 漏洞：同样精确、只在故障时才偏的节点被算成"好节点" |

第二版盲测里，干净约束的软裁判实际漏检 10 / 3 / 0 / 0%，预测 15 / 8 / 5 / 4%；硬裁判平均差 0.12，偏保守。

## 失效地图

七种破坏前提的方式里，只有 ζ（约束和故障共享）会让理论偏乐观，也就是「说挡住了，其实没有」。其余加上修正项之后偏差都在 ±0.05 以内。误差 = 实际漏检 − 预测漏检，每档 80 个随机配置；估计误差约 ±0.03。

| 被破坏的前提 | 原始 ρκλ 最重档（软 / 硬） | 方向 | 修正后（H2） | 补上的东西 |
| --- | --- | --- | --- | --- |
| 约束和故障共享 ζ = 1 | +0.40 / +0.34 | 乐观 | +0.34 / +0.33 | 修不了，是前提 |
| 噪声厚尾 df = 1 | −0.25 / −0.16 | 悲观 | −0.03 / −0.03 | MAD 尺度 |
| δ 每次不同 σ_log = 1.5 | −0.13 / −0.23 | 悲观 | −0.02 / −0.03 | δ 分散度 q；硬裁判逐事件 |
| 节点多 N = 31 | −0.10 / −0.14 | 悲观 | −0.02 / −0.03 | 好节点数 k_good |
| 投毒占多数或少数 | ±0.07 以内 | — | 干净节点多时 −0.12 | 不失效 |
| 相关噪声 c = 0.9 | +0.02 / −0.01 | — | +0.01 / −0.00 | 不失效 |
| 部分节点反向投毒 | +0.02 / +0.02 | — | −0.04 / −0.01 | 不失效 |

ζ 从系统内部原理上看不见，正好对应第一性原理里「区域内的错误不可见」。老失败「自己当答案」就是动态制造 ζ：故障开始后节点误差从 0.19 涨到 10–25，彼此的分散却只有误差的 1–3%，从内部看是高置信的一致。

## 真实 LLM 的发现

- **强模型内部高度自洽**：派生量是现场算的。城市距离和自己报的坐标 100% 自洽，摩尔质量误差 ≤ 0.07%。
- **剩下的错误是共享信念**：7 个模型的密度误差两两相关 0.98，换温度、换提示词几乎不带来独立性。更多模型、更多一致性检查都没用，缺的是信息来源的独立性。
- **开推理照抄资料，关推理拿记忆往回拉**：开推理时 100% 执行资料里的毒（δ = 20% 照样算出 +20%）；关推理后只把 δ 的 15–35% 传进答案，但噪声变大到 5–20%。
