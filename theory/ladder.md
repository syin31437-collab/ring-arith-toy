## 1. 底层：观测可区分性（T0）

世界 w 产生观测分布 P_w。W 是系统认为可能的世界集合，正常集 N、偏离集 D。
- 若存在 w ∈ D、w' ∈ N 使 P_w = P_w'，在这一对世界上，任何算法（等先验、0–1 损失、不允许弃权）都不比瞎猜好。
- 复合假设下的下界（Le Cam）：两类错误之和的最小值 ≥ 1 − TV(conv P_N, conv P_D)。
- 速率：误报固定、独立同分布、T → ∞ 时，漏报 ≈ exp(−T·KL(P_N‖P_D))（Stein）；变点延迟 ≈ log γ / KL（Lorden 1971，分布已知且突变）。这些是渐近结论，序列相依或节点会适应时不直接适用。

杠杆只有两种：**增加观测**、**收窄世界（加假设）**。

## 2. 线性观测下的统一形式（已知，parity-space FDI，Chow–Willsky 1984）

y = H x + f + ε，x 未知（无先验），ε 分布已知且不依赖 (x, f)。
**f 不可见 ⇔ f ∈ col(H)。** 证明：f = H g 时 (x, f) 和 (x + g, 0) 观测分布相同；反之 f ∉ col(H) 时，投影到 col(H) 的正交补上有非零均值，题数足够且 f 跨题稳定时可检验。∎

下面都是它的特例：
- **T1 共同偏移不可见**：所有来源以相同灵敏度测同一标量 θ，H = 全 1 向量。灵敏度不同时结论要改。
- **T3 码距（只在这组假设下）**：标量、中央观察者看到同一份报告、来源对等不可信、偏移跨题稳定、固定非零幅度且 T → ∞（或给出最小可检测幅度）、定位时偏好最少故障：检测 m ≥ e + 1，定位 m ≥ 2e + 1。RAIM 的 5 星检测 / 6 星排除来自冗余度 m − p（p = 4），不是这个式子。
- **T5 约束**：真值满足 Aθ = c。**只看约束残差时**，Af = 0 的偏移不可见；完整观测（比如和别的来源比）可能仍看得见。

换假设门槛就变：有可信来源时可定位任意多个不可信节点；拜占庭、能对不同对象说不同话、无中央观察者时，达成一致要 n ≥ 3e + 1（Lamport–Shostak–Pease 1982）；有签名时大幅放宽（Dolev–Strong 1983）。

## 3. 最小锚定可辨识性（最该补的一条，Kimi 提议）

y_{s,t} = θ_t + b_s + ε，z_t = θ_t + c + η，偏移跨题稳定，噪声零均值独立。
- (a) **c 已知**（秤已校准）：所有 b_s 可由 y_s − z 渐近识别，故障身份可定位。
- (b) **c 未知、θ 无先验，只知"秤不同源、至少有一个未知身份的诚实节点"**：故障身份不可辨识。反例（双世界）：世界 A 真值 θ，秤 θ + b，节点 1 θ、节点 2 θ + b；世界 B 真值 θ + b，秤 θ + b，节点 1 θ、节点 2 θ + b。报告完全相同，谁偏了答案相反。∎ 多一把未校准的秤同样可以构造。
- (c) **相对校准期的变化**：设校准期偏移是 b_s、c，评估期是 b_s + Δ_s、c + Δ_c。此时 Δ_s − Δ_r 和 Δ_s − Δ_c 可识别（差分抵消了未知的 b、c）。所以**"相对自己过去的变化"可辨识的范围，比"相对真值错没错"大得多**，这就是系统能回答的问题；校准期本身已经偏了的部分看不见。

**"独立""诚实""可信""已校准"是四件事，不能混用。**

## 4. 定量（只在写明的高斯假设下）

偏移 μ、差值方差 σ²（节点与秤独立时 σ_i² + σ_c²，相关时要减 2Cov）：逐题 KL = μ²/(2σ²)，延迟首项 ≈ 2σ² log γ / μ²。这是 ρ、κ 与检测的关系。
- 慢漂移 μ_t = vt：累计能量 v²T³/(6σ²) = log γ → T ≈ (6σ² log γ / v²)^{1/3}。启发式，不是 Lorden 意义下的最优延迟定理。
- 只靠历史：若 θ 高斯、方差已知，共同偏移 μ 的信息量是 μ²/[2(σ_θ² + σ²/k)]。**只知道方差不够**：θ = ±1 无噪声、μ = 1 时 KL 无穷，一题即可分开。
- **隐身预算**：把每题偏移的累计能量压在预算内的对手，累计偏差 ≤ σ√(2T log γ)（Cauchy–Schwarz）。这**不是**未检测攻击的普适上限：故障落进不可见方向（col(H)、约束零空间）时，伤害可以任意大而检测不变。

## 5. 互动（原 T4，降级为待测假说）

"依赖就减少通道"是错的：y_j = y_i + (θ + f_j) 依赖 y_i，但 y_j − y_i 恢复了独立测量。相关系数也不等于故障通道数。
只有不可逆地覆盖私有信息，或真正共享故障原因，才减少有效冗余。互动也可能增加可区分性（交叉验证）。**"讨论把相关从 0.04 推到 0.69"是观测事实，它是否减少了检测能力，要单独测。**

## 6. 对 agent 的含义（都是假说）

- 偏离 ≠ 故障：agent 变好也是偏离。
- 主动查询 = 增加观测。但**按需查有漏洞**：对手把偏移压在便宜检测器的线下，秤就永远不被调用；按结果决定查不查也会破坏原有的误报界。常设随机抽查可能比按需查更稳。
- "同伴看得到分裂"不等于"系统知道自己偏了"：过半同偏时最大一致类就是错的那拨，系统会把偏离记在少数头上。

## 7. 可实测且可证伪的预言

底层（T0、col(H)）是数学，不怕数据。能被证伪的是：现实系统是否落在这个模型里；真实噪声下分辨能力够不够；自然偏离（不是注入常数）是否符合。
